# Module 3 Review — 반도체 공정

이번 복습에서는 용어를 따로 외우기보다 “무엇을 해결하기 위한 구조인가”를 설명합니다. 정답은 아래에서 바로 볼 수 있고, 다음 콘텐츠 접근과 관계없습니다.

## Module 전체 핵심 개념 요약

이 Review는 확보한 Module 3의 Lesson 1~9와 수업 중 추가 설명을 바탕으로 **이번 저장소에서 새로 작성한 복습**입니다. 공유된 대화에는 Lesson 9까지 있고 원래 Module Review 본문은 포함되어 있지 않습니다. 원래 복습을 전사한 것으로 표시하지 않습니다.

공정 이름을 순서대로 외우기보다, 지금 만드는 구조에 어떤 변화가 필요한지 물어봅시다. Photo는 PR에 패턴을 준비하고, Etch는 선택적으로 제거하고, Deposition은 막을 쌓습니다. Metal은 도전성 연결을 만들고, CMP는 평탄화합니다. Implant는 도펀트를 주입하고, 열처리는 결정 회복·활성화·확산·산화 등의 목적에 사용됩니다. Clean은 불필요한 오염·잔류물을 제거하여 다음 단계가 안정적으로 진행되도록 돕습니다.

원수업의 현업 분류인 Photo / Etch / Metal / CVD / CMP / Implant / Diffusion / Clean은 담당 영역을 이해하는 지도입니다. 칩을 이 여덟 단계로 한 번씩만 처리하는 제조 순서가 아닙니다. 같은 종류의 작업이 여러 층에서 반복되고 분류가 기술적으로 겹칠 수 있습니다.

## 헷갈리기 쉬운 개념

| 비교 | 구분 기준 |
|---|---|
| Photo / Etch | PR에 패턴을 형성하는 것과 그 패턴을 활용해 재료를 제거하는 것은 다르다. |
| PR / Film | PR은 빛 반응 재료이고, Film은 얇은 막을 뜻한다. 식각할 대상 막은 Photo 전에 형성되어 있을 수 있다. |
| Spinner / Scanner | Spinner는 회전 도포와 관련된 장비·부분, Scanner는 패턴을 노광하는 장비다. Track은 도포·베이크·현상 등의 처리를 통합한다. |
| CVD / Metal | CVD는 화학 반응을 이용한 증착 방식이고 Metal은 금속 재료·배선 형성의 목적이나 조직 분류다. 금속도 CVD로 형성할 수 있다. |
| Implant / Activation | 도펀트를 넣는 것과 들어간 도펀트가 전기적으로 역할을 하도록 만드는 것은 다르다. |
| Oxidation / CVD oxide | 산화는 실리콘과의 반응으로 산화막을 성장시키는 예이고, CVD는 기체 반응으로 막을 증착한다. 같은 SiO₂도 형성 경로가 다르다. |
| CMP / Clean | CMP는 표면 형상을 평탄화하고, Clean은 오염과 잔류물을 제거한다. CMP 후 세정이 필요한 이유다. |

## 개념 사이의 연결 관계

Module 0의 도핑과 MOSFET 구조는 Implant·열처리·증착·식각의 목적을 이해하는 출발점입니다. Module 1의 CMOS 회로를 만들려면 트랜지스터 자체와 연결이 함께 필요합니다. Module 2의 FEOL은 소자, MOL은 중간 접점, BEOL은 금속배선 영역이었습니다. 각 영역에서 여러 공정을 반복하여 구조를 완성합니다.

예를 들어 배선 형성의 개념 흐름은 “절연막 준비 → 패턴 형성 → 홈·구멍 식각 → 필요한 금속층 형성 → 불필요한 표면 금속 제거·평탄화 → 세정·확인”입니다. 실제 공정별 세부 순서는 다르며 이것은 원리를 연결한 예입니다. 구리 다마신은 금속을 무조건 직접 깎는 대신 절연막의 공간에 채우는 발상이라는 점을 기억합니다.

## 연결 연습

금속선 두 개와 그 사이 절연막이 있는 구조를 떠올려보세요. 어떤 공정이 막을 만들고, 어떤 공정이 위치를 정하고, 어떤 공정이 제거하거나 채우고, 어떤 공정이 표면을 준비하는지 설명합니다. 이어 막 두께·간격·연결 불량이 Module 0의 저항·Capacitance와 Module 1의 회로 동작으로 어떻게 이어지는지 말해보세요.

설명 예: 재료와 형상은 전기적 성질을 결정하고, 잘못된 형상이나 오염은 연결과 소자 동작을 바꿀 수 있습니다. 공정 지표를 최종 회로·제품의 의미로 연결하는 것이 목표입니다.

## 즉시 정답 및 해설

1. 아니다. 필요한 구조와 층마다 여러 작업을 반복한다.
2. Overlay, 즉 패턴 간 위치 맞춤이다. 선폭·선명도와 구별한다.
3. 아니다. 예를 들어 먼저 증착한 Film 위에 PR을 도포하고 노광·현상한 뒤 Film을 식각할 수 있다.
4. 목표 재료와 보호할 재료의 식각 속도 차이를 이용해 필요한 부분을 제거한다는 뜻이다.
5. 아니다. 표면 반응이 스스로 제한되는 특성을 활용하는 반복이며 Cycle당 성장량은 공정과 재료에 달려 있다.
6. 가공한 절연막 공간을 금속 배선의 형틀로 활용하는 방식이다. 채운 뒤 표면의 불필요한 금속을 제거한다.
7. 결정 손상을 회복하고 도펀트의 전기적 활성화를 돕기 위해서다. 동시에 원치 않는 확산도 관리해야 한다.
8. 아니다. 열 이력은 확산과 이미 만든 구조에도 영향을 주므로 Thermal Budget을 관리한다.
9. 아니다. 오염은 다음 공정이나 접합·전기 특성에 문제를 줄 수 있어 세정이 필요하다.
10. 전자는 연결과 Metal/Via, 후자는 소자 구조·도핑·게이트 등의 후보를 생각한다. 최종 원인은 공정·검사 증거로 확인한다.
