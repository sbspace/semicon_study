# Module 4 / Lesson 3
## NPU는 무엇을 특별하게 만드는가?

CPU와 GPU를 봤으니 이번에는 NPU야. 이름이 또 나와서 새로운 종류의 반도체 재료처럼 느껴질 수 있지.

하지만 밑바닥에는 여전히 연산 회로와 기억 회로가 있어.

> “그럼 같은 회로를 쓰는데 무엇을 특별하게 만든 거야?”

자주 반복하는 계산과 데이터 이동에 맞춰 배치한 거야. 작은 곱셈 예제부터 보자.

## 오늘 목표는 딱 하나야

> **NPU의 핵심은 신경망에서 자주 하는 계산과 데이터 재사용에 맞춰 회로를 구성하는 거야.**

## 1. 자주 만드는 메뉴에는 전용 기계가 유리하겠지?

**NPU**는 신경망 계산을 효율적으로 처리하도록 만든 처리장치야. **신경망**은 입력값에 가중치를 적용하고 여러 계산 단계를 거쳐 결과를 만드는 인공지능 모델의 한 종류야.

**가중치**는 입력이 결과에 얼마나 영향을 주는지 조절하는 수치야.

여러 요리를 만들 수 있는 주방에도 특정 메뉴를 대량 생산하는 전용 기계를 놓을 수 있어. 재료의 이동과 작업 순서를 메뉴에 맞추면 낭비가 줄어들어.

하지만 메뉴가 달라져 기계가 지원하지 않는 작업이 많아지면 장점이 작아져.

NPU도 “AI를 이해하는 특별한 물질”로 만들어지지 않아. 익숙한 연산 회로와 기억 회로를 특정 계산에 맞게 배치해. NPU라는 이름만으로 모든 제품의 내부 구조가 같아지는 것도 아니야.

## 2. 곱하고 더하는 계산부터 해보자

기계의 이름보다 재료가 어떻게 들어오고 다시 쓰이는지를 보면 좋아. 같은 숫자를 멀리서 매번 가져올 필요가 있을까?

작은 신경망 계산의 일부를 다음처럼 생각해보자.

`출력 = 입력1 × 가중치1 + 입력2 × 가중치2`

입력이 2와 3, 가중치가 4와 5라면 출력은 `2×4 + 3×5 = 23`야. 이 예처럼 곱하고 결과를 더하는 동작을 **MAC**, 즉 곱셈 후 누적이라고 해.

실제 모델은 이런 계산 외에도 여러 종류의 연산을 포함해.

NPU에는 MAC을 반복하는 연산 자원과, 가까이에서 데이터를 재사용하도록 하는 기억 공간이 마련돼. 같은 가중치를 여러 계산에 쓴다면, 멀리서 매번 다시 가져오는 대신 가까이 보관해 쓰는 것이 유리할 수 있어.

계산뿐 아니라 데이터 이동도 에너지를 쓰기 때문이야.

텍스트로 추적하면 `입력·가중치 준비 → 곱셈 → 부분합 누적 → 결과 전달`이야. 앞의 부분합이 다음 누적의 입력이 되고, 여러 출력 계산을 다른 연산 자원에 나누어 배치할 수도 있어.

**학습**은 예시 데이터를 이용해 모델의 가중치를 조정하는 과정이고, **추론**은 준비된 모델로 새 입력의 결과를 계산하는 과정이야. 많은 기기용 NPU는 추론 효율을 중요하게 설계하지만, “NPU는 원리상 학습을 할 수 없다”로 일반화하지는 않아.

## 3. 앞에서 배운 것과 연결해보자

CPU의 명령 실행, GPU의 병렬 처리에 이어, 이번에는 특정 연산과 데이터 흐름에 맞춘 설계를 배웠지. 곱셈기도 더 작은 논리 회로들로 만들어져.

새로운 제품 이름이 나와도 “소자 → 회로 → 기능 블록 → 제품”의 연결은 유지돼.

## 4. 실제로는 어디에 쓰일까?

휴대전화에서 사진을 분류하는 기능을 생각해봐. 해당 모델의 연산을 NPU가 지원하고 소프트웨어가 잘 연결되면 효율적으로 실행할 수 있어.

지원하지 않는 부분은 CPU나 GPU가 처리해야 할 수도 있어.

성능 표의 **TOPS**는 보통 초당 조 단위 연산 수를 뜻해. 하지만 숫자를 비교하려면 어떤 정밀도, 즉 수를 얼마나 자세히 표현하는 형식을 썼는지, 실제로 어떤 연산을 세었는지 확인해야 해. TOPS 하나로 앱의 응답 속도를 판단하기 어려워.

## 5. 잠깐, 네 말로 설명해볼까?

같은 가중치를 100번 쓰는 계산에서, 매번 먼 기억장치에서 가져오는 방식과 한 번 가져와 가까이 두고 반복 사용하는 방식을 비교해 봐.

같이 확인해보자. 계산식은 같아도 두 번째 방식은 먼 데이터 이동을 줄일 여지가 있어.

다만 가까운 기억 공간의 용량이 충분해야 하고, 실제 실행 순서가 재사용을 허용해야 해. “전용 연산기 수”만 보는 것보다 데이터 흐름까지 보는 이유야.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| NPU | 신경망 연산과 데이터 흐름에 맞춘 처리장치 |
| 가중치 | 입력이 결과에 미치는 영향을 조절하는 수치 |
| MAC | 곱셈 결과를 누적하는 연산 |
| 추론 | 준비된 모델로 새 입력의 결과를 계산하는 과정 |

## 오늘 반드시 기억할 3줄

**① NPU의 효율은 연산 구조와 데이터 재사용에서 나와.**

**② 지원하는 연산과 소프트웨어 연결이 실제 활용에 중요해.**

**③ 학습은 가중치를 조정하고, 추론은 준비된 가중치를 사용해.**

**Q1. 입력 2·3, 가중치 4·5의 곱셈 후 합은?**

**Q2. 모든 모델이 NPU에서 자동으로 가장 빠르게 실행될까?**

**Q3. 가중치를 가까이 보관해 여러 번 사용하는 이유는?**

## 정답과 해설

**Q1**

23이야. 2×4+3×5=8+15야.

**Q2**

아니야. 모델 연산 지원, 데이터 이동, 소프트웨어와 실행 조건에 따라 달라져.

**Q3**

먼 기억장치로부터 반복해서 가져오는 데이터 이동을 줄일 수 있기 때문이야.
