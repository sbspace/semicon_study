# Module 5 Review — 첨단 공정

GAA, EUV, 후면 전력 공급. 전부 첨단 기술이라고 묶으면 오히려 헷갈려. 오늘은 각각 “어떤 문제를 해결하려고 바꾼 걸까?”라는 질문으로 정리해보자.

정답은 아래에 바로 있어. 먼저 떠올려보고 확인해봐.

## 1. 먼저 큰 그림부터 다시 보자

첨단 공정의 목표는 작은 숫자의 이름을 얻는 것이 아니라 실제 회로의 전력·성능·면적 조건을 개선하는 거야. 작은 소자에서 게이트 제어가 어려워지는 문제는 FinFET·GAA 같은 형상 변화로 대응해. 작은 패턴의 형성은 EUV·High-NA 등 노광 기술과 재료·식각의 조합으로 대응해. 전력을 회로까지 안정적으로 전달하는 문제에는 후면 전력 공급 같은 배선 구조의 변화가 있어.

이 기술들은 서로 다른 층위의 문제를 해결하며, 실제 공정에서는 함께 제조 가능한 조합으로 통합해야 해.

## 2. 이 말들은 꼭 구분하자

| 비교 | 구분 기준 |
|---|---|
| 노드 이름 vs 실제 치수 | 세대 이름으로 모든 채널·금속 선폭을 알 수 없어. |
| GAA vs 적층 패키지 | 소자 채널의 형상과 여러 다이를 쌓는 구조는 달라. |
| EUV vs 식각 | 빛으로 기록하는 단계와 재료를 제거하는 단계야. |
| High-NA vs 짧은 파장 | High-NA는 같은 EUV에서 광학계의 NA를 높여. |
| GAA vs 후면 전력 공급 | 채널 제어와 전력 배선의 문제를 각각 다뤄. |

## 3. 지금까지 배운 것과 이어보자

Module 0의 전하·전압과 게이트 제어가 소자의 출발점이야. Module 1의 논리 기능을 그 소자로 구현하고, Module 2의 연결망으로 묶어. Module 3의 쌓기·패턴·제거·평탄화가 이를 만들고, Module 4의 제품 요구가 어느 특성을 개선할지 정해.

다음 Module에서는 만들어진 다이를 다른 다이와 보드에 연결해 실제 제품으로 완성해.

## 4. 네 말로 한 번 묶어볼까?

기술 소개에서 “GAA, EUV, 후면 전력 공급을 활용한다”는 문장을 만났다고 해보자. 세 단어를 하나의 첨단 기술로 묶지 말고, 각각 채널 제어·패턴 형성·전력 전달이라는 질문에 연결해 봐.

그다음 확인할 질문은 “그 조합으로 어떤 회로에서 어떤 조건의 성능·전력·면적을 얻었는가?”야. 이것이 구조 이름에서 실제 제품 평가로 넘어가는 설명이야.

## 누적 Quiz — 같이 확인해보자

**Q1. 3nm와 2nm 제품의 실제 성능은 이름만으로 비교 가능할까?**

**Q2. GAA에서 게이트와 채널 사이에는 무엇이 있을까?**

**Q3. Module 1의 인버터 기능이 GAA 도입으로 달라질까?**

**Q4. 노광이 선명해도 연결 구멍 위치가 틀리면 어떤 문제가 남을까?**

**Q5. 0.9V 공급, 1A 전류, 0.03Ω이면 단순 도착 전압은?**

**Q6. GPU가 메모리를 기다린다면 소자 속도 개선만으로 충분할까?**

## 정답과 해설

**Q1**

그렇게는 비교하기 어려워. 회로·배선·전력·작업 종류 등 실제 비교 조건이 필요해.

**Q2**

게이트 절연층이야. 직접 금속 접촉으로 제어하는 구조가 아니야.

**Q3**

기본 논리 관계는 유지돼. 소자의 물리 구현과 특성이 바뀌어.

**Q4**

다른 층과 연결되지 않을 수 있어. 오버레이와 후속 가공까지 확인해야 해.

**Q5**

0.87V야. 저항성 전압 강하는 0.03V야.

**Q6**

아니야. Module 4에서 본 데이터 공급 병목이 남을 수 있어.
