# Module 9 / Lesson 3
## HBM4 발표 읽기 — 용량·대역폭·출하 상태

Module 7에서 HBM의 층 수·용량·대역폭을 따로 읽었지. 이번에는 실제 HBM4 발표를 펼쳐볼 거야.

> “12H는 출하했고 16H는 샘플을 보냈다는데, 둘 다 양산이라는 뜻이야?”

제품마다 상태가 다를 수 있어. 사양 숫자와 공급 단계를 함께 나눠보자.

## 오늘 목표는 딱 하나야

> **같은 발표에 나온 제품도 용량·대역폭·출하 상태를 각각 확인해야 해.**

## 1. 샘플을 보낸 것과 대량으로 공급한 것

**샘플**은 고객의 평가·검증 등을 위해 제공하는 시제품 또는 평가용 제품이야. **대량 출하**는 고객에게 공급되는 생산 물량의 단계에 관한 표현이야.

어느 회사가 사용하는 표현인지, 어떤 제품을 가리키는지 확인해야 해.

새 창고의 축소 모형을 보여준 것, 고객이 시험할 물량을 보낸 것, 정기적으로 큰 물량을 보낸 것은 같은 상황이 아니야. HBM처럼 복잡한 적층 제품에서는 층 수별로 준비 상태가 다를 수 있어.

Module 7에서 층 수와 용량·대역폭을 나누어 읽었지. 그 구분을 실제 2026년 발표에 적용해보자.

## 2. 발표에 적힌 숫자를 하나씩 읽어보자

오늘 숫자를 외울 필요는 없어. GB, H, TB/s가 서로 어떤 질문에 답하는지만 구별하면 돼.

Micron은 **2026년 3월 16일** 발표에서 HBM4 **36GB 12H**의 대량 출하를 2026년 1분기에 시작했다고 밝혔어. 같은 발표의 **48GB 16H**는 고객에게 샘플을 보낸 단계로 설명해.

이 두 제품의 상태를 서로 바꾸어 읽으면 안 돼. [Micron 발표](https://investors.micron.com/news/press-release/2026/Micron-in-High-Volume-Production-of-HBM4-Designed-for-NVIDIA-Vera-Rubin-PCIe-Gen6-SSD-and-SOCAMM2-03-16-2026/default.aspx)

발표는 36GB 12H 제품에 대해 핀당 11Gb/s를 넘는 속도와 2.8TB/s를 넘는 대역폭을 제시해. 이는 제조사가 제시한 제품 수치이며 실제 모든 AI 작업의 처리 속도를 뜻하지 않아.

시험 조건과 비교 기준은 원문 각주를 함께 확인해. [Micron 제품 수치와 각주](https://investors.micron.com/news/press-release/2026/Micron-in-High-Volume-Production-of-HBM4-Designed-for-NVIDIA-Vera-Rubin-PCIe-Gen6-SSD-and-SOCAMM2-03-16-2026/default.aspx)

| 발표에 나온 항목 | 무엇을 뜻하나? | 의미하지 않는 것 |
|---|---|---|
| 36GB | 한 스택의 저장 용량 | 초당 데이터 전송량 |
| 12H | DRAM 다이 적층 수 | GPU 다이 수 |
| TB/s | 시간당 데이터 전달 능력 | 메모리 저장량 |
| 대량 출하 / 샘플 | 해당 제품의 공급·평가 단계 | 다른 층 수 제품의 같은 상태 |

## 3. 층만 늘리면 새로운 HBM 세대가 되는 걸까?

HBM4라는 세대 이름은 전체 인터페이스와 제품 설계의 변화를 가리켜. 높은 층 수만으로 새 세대가 되는 것은 아니야.

기억할 구조는 DRAM 셀과 주변 회로, TSV·다이 접합, 베이스 다이, 연산기까지의 연결이야.

HBM의 외부 전달 능력이 높아지면 연산기 쪽 메모리 인터페이스와 패키지도 이를 사용할 수 있어야 해. 이건 앞에서 배운 연결 구조로 생각해본 거야. 특정 시스템이 얼마나 빨라졌는지는 그 시스템의 측정 결과를 따로 봐야 해.

## 4. 앞에서 배운 것과 연결해보자

Module 4의 계산·메모리 균형, Module 6의 적층·검사, Module 7의 용량과 대역폭이 한 발표 안에 동시에 등장해. Module 8의 생산 단계 개념을 더하면 “어떤 구조의 어느 제품이 어느 단계인가”까지 읽을 수 있어.

## 5. 비교할 때 놓치기 쉬운 조건

같은 회사의 전 세대 대비 개선율도 용량, 층 수, 속도, 작업 패턴이 같거나 비교 조건이 명시되어야 이해할 수 있어. 소비 에너지를 전송 데이터량으로 나눈 효율과 제품 전체의 소비전력도 구별해.

데이터당 효율이 좋아져도 더 많은 데이터를 보내면 전체 전력이 반드시 같은 비율로 줄지는 않아.

여기서는 3월 발표 당시의 상태를 읽은 거야. **2026년 9월의 모든 제조사 공급 현황이나 시장점유율을 나타내는 자료는 아니야.** 그래서 언제 발표했는지, 실제 일은 언제 일어났는지를 함께 봐야 해.

## 6. 잠깐, 네 말로 설명해볼까?

“12H 양산 제품과 16H 샘플이 함께 공개되었으니 16H도 이미 동일하게 대량 출하 중이다”라는 문장을 고쳐봐.

같이 확인해보자. 발표 기준으로 12H는 대량 출하, 16H는 샘플 단계야. 16H의 이후 대량 출하는 새 공식 자료로 확인해야 해.

용량이 크다는 사실이 생산 준비 완료를 대신하지 않아.

## 7. 다음에 이 소식을 다시 읽는다면?

층 수별 제품 상태, 사용 가능한 용량, 대역폭 조건, 고객 검증·실제 출하의 구분을 확인해. 새 자료가 나오면 과거 이정표는 유지하고 현재 상태 설명을 갱신해.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| 샘플 | 평가·검증 등을 위해 제공되는 제품 |
| 대량 출하 | 생산된 제품의 본격적인 공급 단계라는 발표 표현 |
| 12H / 16H | DRAM 다이 12개 / 16개 적층 표기 |
| 전송 효율 | 전달 데이터량에 대한 에너지 사용 등의 효율 |

## 오늘의 Quiz

**Q1. 인용한 2026년 3월 발표에서 48GB 16H는 어떤 단계일까?**

**Q2. 2.8TB/s를 넘는다는 발표가 저장 용량을 나타낼까?**

**Q3. 데이터당 에너지 효율이 좋아지면 전체 소비전력도 반드시 감소할까?**

## 정답과 해설

**Q1**

고객 샘플 제공 단계야. 같은 발표의 36GB 12H 대량 출하와 구별해.

**Q2**

아니야. 시간당 데이터 전달 능력인 대역폭이야.

**Q3**

아니야. 실제 데이터 전송량과 동작 조건에 따라 전체 전력은 달라져.
