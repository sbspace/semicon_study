# Module 8 / Lesson 2
## PDK·EDA·IP — 설계와 공장을 잇는 약속

설계와 제조를 나눠 맡을 수 있다고 했지. 그런데 도면만 넘기면 어느 공장에서나 똑같이 만들 수 있을까?

> “금속선을 얼마나 가깝게 놓아도 되는지 어떻게 알아?”

공정의 특성과 규칙을 설계 쪽에 알려주는 자료가 필요해. 도구와 재사용 부품도 함께 볼 거야.

## 오늘 목표는 딱 하나야

> **PDK는 공정의 모델과 규칙, EDA는 설계 도구, IP는 재사용할 설계야.**

## 1. 설계 프로그램·부품·제작 규칙을 나눠보자

**PDK**는 Process Design Kit로, 특정 반도체 공정에서 설계하는 데 필요한 소자 모델·배선 규칙·검증 정보 등의 묶음이야. **EDA**는 Electronic Design Automation으로, 회로 설계와 검증 등을 돕는 소프트웨어 도구야.

**IP**는 여기서 재사용할 수 있도록 제공되는 설계 자산을 뜻해.

집을 설계한다고 생각해보자. 설계 프로그램은 EDA, 미리 준비한 창문이나 계단 설계는 IP에 비유할 수 있어.

벽 두께와 재료 특성, 시공 가능한 간격 같은 제작 조건은 PDK와 비슷해.

프로그램이 있다고 재료의 물성을 마음대로 바꿀 수는 없어. 좋은 부품 설계도 선택한 제작 방식에 맞아야 해.

세 가지는 서로 대체하는 제품이 아니야.

## 2. 공장의 물리 조건이 설계 정보가 되면?

Module 3에서 실제 막과 패턴을 만들었지? 그때의 제약이 설계에서는 간격 규칙과 소자 모델로 표현되는 거야.

| 필요한 정보 | 설계에서 하는 일 | 앞 수업과 연결 |
|---|---|---|
| 소자 모델 | 입력 전압 등에 따른 전류를 예측 | MOSFET의 전기적 동작 |
| 배선·간격 규칙 | 제조 가능한 형상을 정함 | Photo·Etch의 패턴 한계 |
| 연결·층 정의 | 어떤 금속과 접점을 쓰는지 정함 | FEOL·MOL·BEOL |
| 검증 규칙 | 도면이 조건을 만족하는지 확인 | 실제 제조 전 오류 줄이기 |

PDK는 장비별 제조 Recipe를 그대로 설계자에게 건네는 자료라는 뜻이 아니야. 설계자가 공정 특성을 이용해 설계하고 검증할 수 있는 정보여. Recipe는 장비 공정을 하는 조건이며 정보의 목적과 사용자가 달라.

<interactive type="pdk-eda-ip" />

**DRC**는 Design Rule Check, 즉 도형이 공정의 설계 규칙을 만족하는지 검사하는 것이야. **LVS**는 Layout Versus Schematic으로, 그린 배치·배선이 의도한 회로 연결과 맞는지 비교하는 검사야.

예를 들어 두 금속선이 허용 간격보다 가까우면 DRC에서 문제가 될 수 있어. 간격은 충분하지만 한 선이 잘못된 트랜지스터에 연결되었다면 LVS에서 차이를 찾을 수 있어.

둘 다 통과해도 칩의 모든 기능과 성능이 자동으로 보장되는 것은 아니야. 논리 동작과 시간 조건, 전력 등의 검증도 필요해.

## 3. IP는 어디까지 재사용될까?

Module 2에서 배운 Standard Cell도 재사용 설계의 한 형태야. 더 큰 CPU 코어나 인터페이스 기능도 IP로 제공될 수 있어.

어떤 IP는 기능을 기술한 정보 중심이고, 어떤 IP는 특정 공정의 물리 배치까지 정해진 형태야. 그래서 “같은 기능의 IP”라도 공정을 바꿀 때 다시 구현하거나 검증해야 할 범위가 달라.

## 4. 앞에서 배운 것과 연결해보자

FAB에서 만드는 NMOS·PMOS와 배선의 특성이 설계 쪽에서는 모델과 규칙이 돼. 설계자는 그 정보를 도구에 넣어 회로를 구현해.

물리 구조가 소프트웨어의 설계 정보로 표현되는 연결을 보는 것이야.

## 5. 실제로는 어디에 쓰일까?

공개된 SkyWater SKY130 PDK 문서에서도 소자와 설계 규칙, 층 정의, 검증 관련 항목을 확인할 수 있어. 이 공개 사례는 PDK에 어떤 종류의 정보가 들어가는지 보여줘.

해당 공개판의 사용 가능 범위나 생산 준비 상태를 모든 상용 PDK에 일반화하지 않아.

## 6. 잠깐, 네 말로 설명해볼까?

“EDA를 샀으니 어느 파운드리에서든 같은 설계를 바로 생산할 수 있다”는 말에서 빠진 조건을 설명해봐.

같이 확인해보자. 대상 공정의 PDK와 지원되는 IP가 필요하고, 실제 물리 구현과 검증을 다시 확인해야 해.

도구의 존재와 특정 공정에서 제조 가능한 설계의 완성은 다른 단계야.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| PDK | 특정 공정에서 설계·검증하기 위한 모델과 규칙 묶음 |
| EDA | 설계·검증을 돕는 소프트웨어 도구 |
| IP | 재사용할 수 있는 설계 자산 |
| DRC / LVS | 제조 규칙 검사 / 도면과 회로 연결 일치 검사 |

## 오늘 반드시 기억할 3줄

**① PDK는 공정 정보, EDA는 도구, IP는 재사용 설계야.**

**② DRC와 LVS는 서로 다른 오류를 찾아.**

**③ 공정이 달라지면 재사용 범위와 재검증 필요성을 확인해.**

## 오늘의 Quiz

**Q1. 배선 간격이 공정 규칙보다 좁은 문제와 연결 대상이 틀린 문제는 각각 무엇으로 검사할까?**

**Q2. PDK는 모든 장비의 Recipe를 그대로 공개한 것일까?**

**Q3. 특정 공정의 물리 배치 IP를 다른 공정으로 바로 옮겨도 될까?**

## 정답과 해설

**Q1**

앞의 것은 DRC, 뒤의 것은 LVS가 관련돼.

**Q2**

아니야. 설계·검증에 필요한 공정 정보 묶음이야.

**Q3**

일반적으로 그렇게 가정하면 안 돼. 대상 공정 지원과 구현·검증 범위를 확인해야 해.
