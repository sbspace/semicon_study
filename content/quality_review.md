## 중복과 난이도 조정

원수업의 실제 반복 설명은 삭제하지 않았습니다. Module 2에서 패키지·칩렛을 처음 소개하고 Module 6에서 연결·접합·검사로 확장합니다. Module 4는 연산기 역할과 메모리 균형, Module 7은 그 공급 문제를 HBM 구조로 연결합니다. Module 5는 첨단 공정의 원리, Module 9는 그 원리로 실제 발표의 상태와 비교 조건을 읽는 연습입니다.

다른 세션에 반복 발행된 기존 수업은 정규 Lesson에 섞어 늘리지 않고 별도 보충 원문으로 제공합니다. 최신 후속 회차의 설명도 대조했습니다. 중복의 이유와 번호 충돌은 source_map.md에 남겼습니다.

용어가 상세 설명보다 먼저 등장하는 원수업 예고 부분에는 필요한 최소 정의를 추가했습니다. 깊은 설명은 원래 순서를 유지합니다. 소자 적층과 다이 적층, 공정 방식과 재료·조직 분류처럼 구분 기준이 다른 단어는 비교 설명을 덧붙였습니다.

## 보존을 위해 유지한 예외와 한계

- 공유된 Module 3 대화에는 원래 Review 본문이 없어 새 복습으로 보완했습니다. 원문 복원으로 주장하지 않습니다.
- 원수업 Lesson의 제목·Quiz 배치는 서로 다릅니다. 원래 4개 문항 또는 5개 용어로 제시된 부분은 일괄 삭제하지 않았습니다.
- 긴 질의응답은 정규 본문 뒤에 보존했습니다. 기본 10~15분과 별도의 추가 학습 시간이 필요할 수 있습니다.
- 실제 외부 이미지 파일은 동봉하지 않았습니다. 표시 위치와 설명을 남겼고, 원래 ASCII를 유지했습니다. 도식 UI의 동작이나 외부 이미지 렌더링을 검증했다는 뜻은 아닙니다.
- Module 9는 표시한 공식 자료에서 확인한 이정표와 원리를 다룹니다. 모든 회사의 최신 공급 현황을 전수 조사한 시장 보고서는 아닙니다.
- 외부 링크의 미래 지속성은 보장할 수 없습니다. 원수업 참고 링크는 출처 기록이며, 신규 사실 확인 자료와 구별합니다.

검토에 사용한 임시 작성·검사 스크립트와 대화의 개인 운영 기록은 최종 content/에 포함하지 않았습니다.
