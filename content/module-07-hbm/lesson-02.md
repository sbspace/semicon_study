# Module 7 / Lesson 2
## HBM 스택 안과 밖 — DRAM, TSV, 베이스 다이

HBM은 데이터 통로가 넓은 메모리라고 했지. 이제 그 안을 옆에서 잘라보자.

DRAM이 여러 장 쌓여 있고 아래에는 베이스 다이가 있어. 여기서 많이 헷갈리는 게 하나야.

> “그럼 GPU도 그 맨 아래에 있는 거야?”

스택 안과 스택 밖을 구분하면 바로 정리돼.

## 오늘 목표는 딱 하나야

> **HBM 내부의 수직 연결과, HBM에서 옆의 GPU로 가는 연결을 따로 봐야 해.**

## 1. 여러 층 창고와 아래층 출하장을 떠올려봐

**스택**은 여러 층을 쌓은 구조야. HBM에서는 데이터를 저장하는 DRAM 다이 여러 장이 수직으로 쌓여. **베이스 다이**는 스택 아래에서 연결과 인터페이스 등의 기능을 담당하는 다이야.

세대와 제품에 따라 내부 기능과 만드는 공정은 달라질 수 있어.

여러 층 창고에 물건이 저장되어 있고, 층 사이의 승강기와 아래층 출하장을 통해 밖으로 내보낸다고 생각해보자. 창고 층은 DRAM 다이, 층 사이 전기 연결은 TSV 등의 연결, 출하장에 해당하는 부분은 베이스 다이야.

물건을 쓰는 큰 공장은 옆의 GPU에 비유할 수 있어.

이 비유의 핵심은 “쌓인 메모리 내부”와 “그 메모리를 쓰는 연산기”의 위치를 분리하는 것이야.

## 2. DRAM 다이에서 GPU까지 길을 따라가자

Module 6에서 배운 TSV와 접합부를 이 단면에 다시 놓아보자. 아는 부품들이 모여 있는 구조야.

Module 6의 **TSV**는 실리콘을 관통하는 전기 연결이었어. HBM에서 여러 다이 사이의 데이터를 수직으로 전달하는 데 사용돼. TSV만 있으면 다이들이 저절로 접촉하는 것은 아니야. 다이 표면 사이를 연결하는 접합 구조도 필요해.

| 위치 | 구조 | 하는 일 |
|---|---|---|
| DRAM 다이 내부 | 메모리 셀·주변 회로 | 데이터 저장과 선택·읽기·쓰기 |
| 실리콘 관통 부분 | TSV | 위아래 방향의 전기 연결 |
| 다이와 다이 사이 | 접합부 | 서로 다른 다이의 연결 지점을 이어줌 |
| 스택 아래 | 베이스 다이 | 외부와의 연결·인터페이스 등 |
| 스택 밖 | 인터포저 등의 패키지 배선 | HBM과 연산 다이를 연결 |

대표적인 구성에서 HBM 스택과 GPU 다이는 인터포저 위에 나란히 있어. HBM이 여러 층이라고 해서 GPU가 반드시 HBM 바로 아래에 있는 것은 아니야. 제품별 구현은 다르지만, 이 대표 구조를 먼저 잡으면 적층 사진을 읽기 쉬워.

## 3. 주소 하나를 읽는 흐름

**메모리 컨트롤러**는 메모리에 보낼 요청의 순서와 동작을 관리하는 회로야. GPU 쪽 컨트롤러가 읽기 요청을 만들고, 물리적 신호를 주고받는 인터페이스 회로와 패키지 연결을 거쳐 HBM에 전달해. 선택된 DRAM 영역에서 읽은 데이터가 연결을 따라 되돌아와.

베이스 다이를 “GPU 전체의 메모리 컨트롤러가 통째로 내려간 것”이라고 단정하지 않아. 컨트롤러, 신호 인터페이스, DRAM 주변 회로의 기능은 구분해야 해.

세대가 바뀌어 베이스 다이 기능이 늘어도 HBM이 곧 GPU가 되는 것은 아니야.

## 4. 앞에서 배운 것과 연결해보자

소자 규모의 나노시트 적층, 칩 내부 BEOL 금속 적층, HBM 다이 적층은 모두 “층”이라는 말을 쓰지만 크기와 목적이 달라. HBM 다이 안에도 소자와 배선이 있고, 그 완성된 다이를 다시 여러 장 쌓아.

## 5. 실제로는 어디에 쓰일까?

HBM에는 DRAM 셀을 잘 만드는 능력과 얇은 다이를 가공·정렬·접합하는 능력이 함께 필요해. 사진에서 층 수만 세면 셀 특성과 연결 신뢰성, 열 문제를 놓치기 쉬워.

제조 부문과 패키징 부문이 함께 일해야 하는 제품이라는 의미야.

## 6. 잠깐, 네 말로 설명해볼까?

HBM과 GPU가 놓인 단면을 말로 그려봐. “DRAM 다이 안의 배선”, “실리콘을 뚫은 TSV”, “다이 사이 접합”, “GPU로 가는 배선”을 서로 다른 네 위치로 가리킬 수 있으면 돼.

같이 확인해보자. TSV는 스택 내부 수직 경로이고, 인터포저 배선은 스택 밖에서 옆의 GPU로 가는 경로야. 두 연결을 모두 관리해야 데이터가 연산기에 도착해.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| 스택 | 여러 다이를 수직으로 쌓은 구조 |
| 베이스 다이 | HBM 아래에서 연결·인터페이스 등의 기능을 하는 다이 |
| TSV | 실리콘 관통 전기 연결 |
| 메모리 컨트롤러 | 메모리 요청과 동작을 관리하는 회로 |

## 오늘 반드시 기억할 3줄

**① HBM은 DRAM 다이와 베이스 다이, 수직·외부 연결을 함께 봐.**

**② TSV와 다이 사이 접합부, 인터포저 배선은 다른 위치야.**

**③ 대표적인 2.5D 구성에서 GPU는 HBM 스택 옆에 있어.**

## 오늘의 Quiz

**Q1. TSV와 인터포저 배선은 같은 위치의 구조일까?**

**Q2. 베이스 다이에는 반드시 GPU의 전체 메모리 컨트롤러가 들어가는가?**

**Q3. GAA 나노시트 세 장과 HBM DRAM 다이 세 장은 같은 적층일까?**

## 정답과 해설

**Q1**

아니야. TSV는 실리콘을 관통하고 인터포저 배선은 다이 사이를 연결해.

**Q2**

그렇게 일반화할 수 없어. 기능 분담은 구별하고 제품별 구현을 확인해야 해.

**Q3**

아니야. 앞의 것은 소자 내부 채널, 뒤의 것은 완성된 다이의 적층이야.
