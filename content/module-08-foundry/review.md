# Module 8 Review — 파운드리 생태계

설계 회사, 제조 공장, 패키징 업체가 모두 등장했어. 이제 가상의 칩 하나가 설계도에서 실제 제품으로 나오는 길을 따라가면서 누가 무엇을 맡는지 정리해보자.

정답은 아래에 바로 있어. 먼저 떠올려보고 확인해봐.

## 1. 먼저 큰 그림부터 다시 보자

반도체 산업은 제품을 정의하고 설계하고 웨이퍼를 제조하고 조립·검사하는 역할이 연결된 구조야. PDK는 공정 모델·규칙, EDA는 도구, IP는 재사용 설계야. Tape-out 뒤에도 물리 제조와 제품 검증이 남아. 제품 공급은 수율뿐 아니라 생산능력·기간·패키지 준비에 의해 결정돼.

## 2. 이 말들은 꼭 구분하자

| 비교 | 구분 기준 |
|---|---|
| 사업 모델 / 불량 원인 | 누가 어느 일을 맡는지와 어느 단계에서 문제가 생겼는지는 따로 확인해. |
| PDK / Recipe | 설계용 공정 정보와 장비 가공 조건은 목적이 달라. |
| DRC / LVS | 형상 규칙과 회로 연결 일치 여부를 각각 확인해. |
| Tape-out / 출하 | 설계 데이터 제출과 실제 제품 공급은 다른 이정표야. |
| 수율 / 생산능력 / 리드타임 | 양품 비율·기간당 처리량·총 소요 시간을 구분해. |

## 3. 지금까지 배운 것과 이어보자

Module 0~3에서 배운 물리 구조가 PDK와 설계 규칙으로 표현되고, EDA와 IP를 활용한 설계가 실제 공정으로 돌아가. 다이 제조 뒤에는 Module 6~7의 조립과 연결이 필요해. 이 전체를 볼 수 있어야 “새 공정 발표”와 “제품 공급 확대” 사이에 남은 과제를 이해할 수 있어.

## 4. 네 말로 한 번 묶어볼까?

가상의 제품 출시 회의에서 설계·제조·패키징 담당자에게 할 질문을 두 개씩 적어봐. 예: 기능과 타이밍 검증은 끝났나? 제조 공정과 수율은 준비되었나? 패키지 연결과 최종 검사 조건은 검증되었나? 답변이 각각 다른 단계의 증거라는 점까지 설명해.

## 정답과 해설

**Q1**

앞의 것은 설계·제품 기획, 뒤의 것은 고객 설계의 웨이퍼 제조야.

**Q2**

아니야. 한 회사가 여러 사업 역할을 가질 수 있어.

**Q3**

LVS야. 형상 규칙 중심의 DRC와 구별해.

**Q4**

아니야. 실제 제조·검사에 대한 정보가 별도로 필요해.

**Q5**

95%야. 380÷400이며, 웨이퍼 전체 다이 수를 분모로 한 수율과 구별해.

**Q6**

예: 목표 전기 특성, IP·PDK 지원, 비용과 공급 조건. 패키지와 검사 능력도 고려해.
