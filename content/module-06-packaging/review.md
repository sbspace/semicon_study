# Module 6 Review — 패키징

다이를 만들었다고 제품이 끝나는 건 아니었지? 전기를 연결하고, 여러 다이를 묶고, 검사하고, 열도 빼야 했어. 다이 하나를 손에 들었다고 생각하고 바깥으로 연결해보자.

정답은 아래에 바로 있어. 먼저 떠올려보고 확인해봐.

## 1. 먼저 큰 그림부터 다시 보자

패키지는 다이를 연결·보호하고 전원과 열 경로를 마련해. 2.5D는 대표적으로 다이 사이의 수평 고밀도 연결, 3D는 다이 적층과 수직 연결이 중심이야. TSV는 실리콘 관통 통로이고 접합부와는 구분해. 다이 검사와 조립 후 검사를 함께 거쳐 제품의 기능을 확인해야 해.

## 2. 이 말들은 꼭 구분하자

| 비교 | 구분 기준 |
|---|---|
| Pad / Bump | 접점 영역 / 돌기형 연결 구조 |
| Chiplet / 3D | 기능을 나눈 다이 / 다이를 적층하는 배치 방식 |
| TSV / Microbump | 실리콘 내부 통로 / 다이 경계 접점 |
| KGD / 최종 양품 | 개별 검사 결과 / 조립된 제품의 평가 |

## 3. 지금까지 배운 것과 이어보자

소자와 BEOL로 만든 다이를 밖으로 연결하는 곳이 패키지야. 여러 다이를 묶으면 통신·전원·열·검사의 문제가 함께 생겨. Module 7에서는 이 원리를 DRAM 적층 제품인 HBM에 적용해.

## 4. 네 말로 한 번 묶어볼까?

두 연산 다이를 옆으로 놓은 제품을 그린다고 생각해봐. 다이, 중간 배선, 범프, 패키지 기판, PCB를 말로 배치한 뒤 전원·신호·열 경로를 각각 설명해봐. 정답의 핵심은 경로가 모두 동일하지 않고, 다이 경계에는 실제 연결 구조가 필요하다는 것이야.

## 누적 Quiz — 같이 확인해보자

**Q1. BEOL과 패키징을 같은 말로 봐도 될까?**

**Q2. GPU 옆에 HBM 스택이 놓였을 때 수평·수직 구조를 구분해봐.**

**Q3. 실리콘을 관통하는 것은 TSV와 Bump 중 무엇일까?**

**Q4. 접점이 촘촘해지면 Clean의 중요성이 없어질까?**

**Q5. 다이 검사만으로 최종 패키지 수율을 알 수 있을까?**

**Q6. Chiplet의 비용을 평가할 때 웨이퍼 비용만 보면 될까?**

## 정답과 해설

**Q1**

아니야. 다이 내부 배선과 다이의 제품 수준 통합을 구분해.

**Q2**

GPU와 스택 사이는 수평 연결, 스택 안의 DRAM 다이는 수직 적층이야.

**Q3**

TSV야. Bump는 접합면에서 접점을 잇는 구조야.

**Q4**

아니야. 작은 오염도 접합과 연결을 방해할 수 있어.

**Q5**

아니야. 조립·연결·최종 동작 조건이 추가돼.

**Q6**

아니야. 패키지·연결·검사와 전체 양품 수를 함께 봐야 해.
