# 이미지와 Interactive Diagram 위치

실제 UI와 이미지 자산은 이 저장소의 구현 범위가 아닙니다. 각 슬롯 바로 옆의 원문 그림·설명을 읽으면 이미지 없이도 핵심을 따라갈 수 있습니다. 모든 슬롯은 선택적 보강이며 콘텐츠 접근 조건이 아닙니다.
