# Module 7 Review — HBM

HBM을 보면 이제 층 수만 세지는 않겠지? 어디에 데이터를 저장하고 어느 길로 꺼내 보내는지 한 번에 설명해보자.

정답은 아래에 바로 있어. 먼저 떠올려보고 확인해봐.

## 1. 먼저 큰 그림부터 다시 보자

HBM은 DRAM 저장 기능에 적층과 넓은 인터페이스를 결합한 제품이야. TSV는 실리콘을 관통하고 접합부는 다이 사이를 이으며, 패키지 배선은 연산기까지 연결해. 용량은 저장량, 대역폭은 시간당 이동량, 지연 시간은 요청이 결과를 얻기까지의 시간이야. 이 세 기준을 먼저 분리하면 세대·적층 수·제품 사양을 읽기 쉬워져.

## 2. 이 말들은 꼭 구분하자

| 비교 | 구분 기준 |
|---|---|
| 높은 적층 / 높은 대역폭 | 층 수는 용량을 늘리는 수단이며, 외부 대역폭은 데이터 폭과 연결당 전송률을 별도로 확인해. |
| 베이스 다이 / GPU | 베이스 다이는 스택의 연결·인터페이스 등을 담당해. GPU는 별도의 연산기야. |
| TSV / 접합부 / 인터포저 | 실리콘 내부 관통, 다이 사이 연결, 다이 간 패키지 배선이라는 위치 차이가 있어. |
| 사양 최대값 / 실제 처리량 | 내부 접근·요청 패턴·계산·온도가 실제 결과에 영향을 줘. |

## 3. 지금까지 배운 것과 이어보자

Module 0의 전기와 소자가 DRAM 셀의 바탕이고, Module 3의 가공과 표면 제어가 제조의 바탕이야. Module 6의 다이 연결이 여러 DRAM을 제품으로 묶어. HBM은 Module 4에서 본 연산기의 데이터 공급 문제를 해결하는 한 방법이야. 다음 Module에서는 이 서로 다른 기술을 누가 설계하고 제조하고 조립하는지 배울 거야.

## 4. 네 말로 한 번 묶어볼까?

가상의 AI 제품을 “연산 다이 하나 + HBM 스택 네 개”로 설명해봐. 각 스택의 용량과 대역폭을 따로 정하고 합계를 계산한 뒤, 실제 성능을 보장하지 않는 조건 두 개를 덧붙이야. 마지막으로 DRAM 제조와 다이 접합을 서로 다른 일로 구분해 말해봐.

## 누적 Quiz — 같이 확인해보자

**Q1. 24Gb DRAM 8장을 합하면 몇 GB인가?**

**Q2. 가상 데이터 연결 1,024개, 연결당 4Gb/s의 이론 대역폭은?**

**Q3. 그 스택의 DRAM 층 수만 1.5배로 늘리면 외부 대역폭도 1.5배일까?**

**Q4. HBM이 GPU 바로 위에 있어야만 하는가?**

**Q5. CMP와 Clean이 HBM 접합과 연결되는 이유는?**

**Q6. 메모리를 바꿔도 프로그램 속도가 같다면 먼저 할 일은?**

## 정답과 해설

**Q1**

24GB야. 24×8÷8이야.

**Q2**

512GB/s야. 1,024×4÷8이야.

**Q3**

아니야. 외부 인터페이스 폭과 핀당 전송률을 확인해야 해.

**Q4**

아니야. 대표적 2.5D 구성에서는 같은 인터포저 위에 나란히 배치해.

**Q5**

평탄하고 깨끗한 표면이 안정적인 접합을 만드는 데 중요하기 때문이야.

**Q6**

실제 병목 구간을 측정해. 계산·내부 접근·연결·온도 등을 확인해.
