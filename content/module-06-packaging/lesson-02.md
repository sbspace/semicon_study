# Module 6 / Lesson 2
## 2.5D와 3D — 옆으로 연결할까, 위로 쌓을까?

다이 하나를 바깥과 연결하는 방법을 봤어. 이번에는 패키지 안에 다이를 두 개 넣어보자.

> “옆으로 놓을까? 위로 쌓을까?”

Module 2의 Chiplet이 여기서 다시 나와. 기능을 나눈 다이들을 실제로 어떻게 연결하는지 볼 거야.

## 오늘 목표는 딱 하나야

> **기능을 여러 다이로 나누는 것과, 그 다이를 옆으로 놓거나 위로 쌓는 것은 구분해야 해.**

## 1. 옆 건물로 갈까, 위층으로 올라갈까?

지난 Lesson에서는 다이 하나가 바깥으로 나가는 길을 봤어. 이번에는 다이 여러 개가 같은 패키지 안에서 서로 연결되는 경우야.

**Die-to-Die 연결**은 말 그대로 다이와 다이 사이에서 데이터를 주고받는 연결이야.

서로 자주 오가는 두 건물을 생각해봐. 멀리 있는 큰 도로로 돌아가는 대신 건물 사이에 짧은 통로를 놓으면 편하겠지.

다이도 비슷해. 다만 거리가 짧아지는 것만으로 모든 문제가 해결되지는 않아.

통로 수와 신호 품질, 연결 회로가 함께 맞아야 해.

## 2. 2D·2.5D·3D는 연결 위치를 보면 쉬워

이름의 숫자보다 다이의 위치와 연결 경로를 먼저 봐봐. 중간에 어떤 구조가 필요한지가 보일 거야.

**Interposer(인터포저)**는 여러 다이와 패키지 기판 사이에서 촘촘한 배선을 제공하는 중간 연결 구조야. 실리콘으로 만들 수도 있고 다른 재료를 쓸 수도 있어.

**2.5D**는 대표적으로 다이를 옆으로 배치하고 이런 고밀도 중간 연결을 이용하는 구조를 말해. **3D 적층**은 다이를 위아래로 쌓고 수직 방향의 전기 연결을 이용하는 구조야.

명칭은 업체의 제품 분류에 따라 범위가 조금씩 다를 수 있어.

| 질문 | 대표적인 2.5D 구조 | 대표적인 3D 구조 |
|---|---|---|
| 다이는 어디에? | 옆으로 나란히 | 위아래로 적층 |
| 다이 사이는 어떻게? | 인터포저·브리지 등의 촘촘한 배선 | 수직 접점과 연결 |
| 얻으려는 이점 | 넓고 짧은 다이 간 연결 | 작은 면적과 짧은 수직 경로 |
| 함께 어려워지는 점 | 연결 구조의 크기와 비용 | 열·정렬·적층 후 검사 |

**Bridge(브리지)**는 필요한 경계 부근에 놓는 작은 연결 다리라고 이해하면 돼. 전체 다이 아래를 넓게 덮는 인터포저와는 모양과 적용 범위가 달라질 수 있어.

여기서 ‘입체적으로 생겼으니 전부 3D 패키지’라고 부르면 구분이 사라져. 일반 패키지도 실제 높이는 있지만, 기술 분류의 3D는 다이의 적층과 수직 연결을 가리켜.

## 3. Chiplet과 패키징은 무엇이 다를까?

Module 2의 **Chiplet**은 큰 시스템의 일부 기능을 담당하도록 나눈 다이였어. Chiplet은 기능을 나누는 방식과 부품을 말하고, 2.5D·3D는 그 다이를 배치하고 연결하는 방법을 말해. Chiplet을 옆으로 놓을 수도, 위로 쌓을 수도 있어.

그래서 ‘Chiplet이면 무조건 3D’도 아니고 ‘옆에 있으면 그냥 PCB 연결’도 아니야. 어떤 배선 구조를 통해 연결했는지까지 봐야 해.

## 4. 앞에서 배운 것과 연결해보자

Module 2의 다이 안팎 연결에서 출발해, Module 3에서 제조한 다이를 제품으로 묶는 구조를 보고 있어. 앞 Module의 소자·배선 성능이 실제 제품에서 발휘되려면 패키지 연결도 함께 맞아야 해.

## 5. 실제로는 어디에 쓰일까?

Intel은 EMIB를 다이 사이 연결에 쓰는 브리지 기술로, Foveros 계열을 여러 다이의 통합에 쓰는 기술로 소개해. 이런 상표는 기본 구조를 이해한 다음 연결하면 돼.

먼저 다이 위치와 통로를 보고 나중에 이름을 붙이자.

다음 Module의 HBM에서도 두 방향이 함께 등장해. HBM 내부 DRAM 다이는 위로 쌓이고, HBM 스택과 연산 다이는 옆으로 배치해 연결할 수 있어. 같은 패키지 안에 서로 다른 차원의 연결이 공존하는 거야.

## 6. 잠깐, 네 말로 설명해볼까?

GPU 다이 하나 옆에 메모리 스택 두 개가 있고, 모두 중간 배선판 위에 있다고 해보자. 무엇을 ‘옆으로 연결’했고 무엇을 ‘위로 적층’했는지 구분해봐.

같이 확인해보자. GPU와 각 메모리 스택은 옆으로 연결됐어. 각 스택 내부의 메모리 다이는 위로 적층됐어.

사진 전체에 2D 또는 3D 이름 하나만 붙이는 것보다 이 두 관계를 나누는 게 정확해.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| Interposer | 다이 사이에 촘촘한 배선을 제공하는 중간 연결 구조 |
| 2.5D | 다이를 주로 옆으로 배치해 고밀도 중간 배선으로 연결하는 방식 |
| 3D 적층 | 다이를 위아래로 쌓아 수직 연결하는 방식 |
| Bridge | 다이 경계 등에 배치하는 작은 연결 구조 |

## 오늘 반드시 기억할 3줄

**① Chiplet은 기능 분할, 2.5D·3D는 배치와 연결의 관점이야.**

**② 한 패키지 안에 수평 연결과 수직 적층이 함께 있을 수 있어.**

**③ 짧은 연결의 이점과 열·정렬·비용의 부담을 함께 봐.**

## 오늘의 Quiz

**Q1. Chiplet을 쓰면 반드시 위로 쌓아야 할까?**

**Q2. HBM 스택 옆에 GPU가 있으면 스택 내부 DRAM도 모두 평면 배치일까?**

**Q3. 인터포저와 PCB를 같은 연결 밀도의 동일한 판이라고 봐도 될까?**

## 정답과 해설

**Q1**

아니야. 옆으로 놓고 연결할 수도 있어.

**Q2**

아니야. 스택 내부는 수직 적층, GPU와 스택 사이는 수평 배치일 수 있어.

**Q3**

아니야. 역할과 배선 규모가 다른 구조야.
