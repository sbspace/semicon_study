# Module 5 / Lesson 3
## EUV는 작은 패턴을 어떻게 더 선명하게 만들까?

지난 시간에는 채널 모양을 바꿨어. 그런데 그 작은 모양은 웨이퍼에 어떻게 정확히 만들까?

여기서 Module 3의 Photo가 다시 등장해.

> “빛으로 더 작은 패턴을 그리면 되겠네?”

맞아. 다만 빛으로 기록한 것과 실제 막을 가공한 것은 나눠서 봐야 해.

## 오늘 목표는 딱 하나야

> **EUV는 작은 패턴을 기록하는 노광 기술이고, 실제 구조는 현상·식각 같은 뒤 공정과 함께 완성돼.**

## 1. 빛으로 작은 무늬를 비춘다고 생각해봐

**노광**은 빛에 반응하는 재료에 패턴을 기록하는 과정이야. 그 재료를 **포토레지스트**, 줄여서 PR이라고 해.

**마스크**는 옮길 패턴 정보를 가진 원판이야. 공정에 따라 빛을 투과시키거나 반사하는 방식이 달라.

벽에 작은 무늬를 투영한다고 생각해보자. 흐릿한 두 선이 겹쳐 보이면 서로 다른 선으로 나누기 어려워.

아주 작은 패턴을 만들려면 먼저 그 차이가 잘 보이도록 빛으로 기록해야 해. 하지만 무늬를 비췄다고 벽이 저절로 깎이는 것은 아니야.

반도체에서도 노광은 패턴 기록 단계야. 이후 현상으로 PR 패턴을 만들고, 식각 등으로 아래 재료에 옮겨.

빛이 완성된 트랜지스터를 한 번에 새기는 것으로 생각하지 않아.

## 2. PR에 기록한 패턴이 실제 막으로 옮겨지기까지

벽에 그림자를 비췄다고 벽이 그 모양으로 깎이지는 않지? 웨이퍼에서도 빛이 맡는 일과 식각이 맡는 일을 구별하자.

**해상도**는 가까운 작은 패턴을 구별해 형성하는 능력이야. **EUV**는 극자외선으로, 반도체 노광에서는 약 13.5nm 파장의 빛을 사용해.

파장은 빛의 공간적인 반복 길이야. 짧은 파장은 더 작은 패턴을 표현하는 데 유리하지만 광학계와 재료, 공정 조건도 함께 영향을 줘.

| 흐름 | 일어나는 변화 |
|---|---|
| PR 도포 | 표면에 빛 반응 재료를 준비 |
| 노광 | PR에 패턴에 따른 반응 차이 형성 |
| 현상 | 반응 차이를 이용해 PR의 일부를 제거 |
| 패턴 전달 | PR 또는 다른 마스크 층을 이용해 아래 재료 가공 |

EUV에서는 빛이 많은 물질에 흡수되기 쉬워 진공 환경과 반사 광학계를 사용해. **NA**, 즉 개구수는 광학계가 빛을 모으고 세부 구조를 구분하는 능력과 관련된 수치야. High-NA EUV는 EUV의 파장을 더 줄인 이름이 아니라 NA를 높인 방식이야. ASML 설명의 비교는 기존 0.33과 High-NA 0.55야.

작은 패턴을 만들려면 이전 방식에서 한 층의 패턴을 여러 번 나누어 만드는 경우도 있어. 이를 **멀티 패터닝**이라고 해.

더 나은 노광은 필요한 반복을 줄일 여지가 있지만, 모든 층과 모든 제품에서 반복 공정이 사라지는 것은 아니야.

## 3. 앞에서 배운 것과 연결해보자

Module 3의 포토와 식각은 서로 다른 역할이야. Module 5 Lesson 2의 핀과 시트 구조도 정밀한 패턴 형성이 필요해. 다만 더 좋은 노광 장비만 들이면 GAA의 모든 제조 문제가 해결되는 것은 아니야.

쌓은 층의 균일성, 선택적 식각과 재료 형성도 함께 맞아야 해.

## 4. 실제로는 어디에 쓰일까?

FAB에서는 선폭뿐 아니라 **오버레이**, 즉 서로 다른 단계에서 만든 패턴 사이의 위치 맞춤도 봐. 구멍이 아무리 작고 깨끗해도 아래 연결 지점에서 벗어나면 문제가 돼.

장비의 해상도, 생산 속도, 공정 수와 결함을 같이 평가하는 이유야.

## 5. 잠깐, 네 말로 설명해볼까?

“사진을 더 선명하게 찍었다”와 “아래 금속을 정확히 깎았다”를 분리해서 설명해 봐.

같이 확인해보자. PR에 잘 기록하는 것은 노광의 성과이고, 아래층의 원하는 형상을 얻는 것은 현상과 패턴 전달까지 포함한 결과야. High-NA는 빛으로 표현하는 능력을 개선하지만, 최종 형상을 결정하는 후속 공정의 역할을 없애지는 않아.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| EUV | 반도체 노광에서 약 13.5nm 파장을 사용하는 극자외선 기술 |
| NA | 광학계의 집광·해상 능력과 관련된 개구수 |
| 멀티 패터닝 | 한 층의 미세 패턴을 여러 단계로 나누어 형성하는 방식 |
| 오버레이 | 서로 다른 패턴 단계의 위치 맞춤 |

## 오늘 반드시 기억할 3줄

**① 노광은 PR에 패턴을 기록하고, 식각은 재료를 제거해.**

**② High-NA EUV는 파장보다 광학계의 NA를 높인 변화야.**

**③ 최종 패턴의 품질은 노광·재료·현상·식각·정렬이 함께 결정해.**

## 오늘의 Quiz

**Q1. EUV 노광만 끝나면 아래층 금속도 원하는 모양으로 모두 깎였는가?**

**Q2. High-NA EUV는 EUV보다 파장을 더 짧게 한 기술일까?**

**Q3. 패턴이 선명해도 아래층 접점에서 어긋났다면 무엇을 확인해야 할까?**

## 정답과 해설

**Q1**

아니야. PR 현상과 후속 패턴 전달 등의 과정이 필요해.

**Q2**

아니야. 같은 EUV 파장 영역에서 NA를 높이는 방향이야.

**Q3**

오버레이를 확인해. 선명도와 층 사이 위치 맞춤은 다른 문제야.
