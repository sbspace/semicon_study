# Module 4 / Lesson 5
## SRAM·DRAM·NAND는 왜 함께 필요할까?

SoC 안에서 계산하는 블록과 데이터를 주고받는 길을 봤어. 그런데 그 데이터는 어디에 놓아둘까?

Module 1에서 SRAM을 배웠지. 여기에 DRAM과 NAND까지 나오면 “그냥 메모리 하나 쓰면 안 되나?” 싶을 거야.

오늘은 가까이 두고 쓸 것과 오래 보관할 것을 나누어 생각해보자.

## 오늘 목표는 딱 하나야

> **SRAM·DRAM·NAND는 기억하는 구조가 달라서, 잘 맞는 역할도 달라.**

## 1. 손안의 메모와 책상, 보관함은 왜 따로 있을까?

**메모리**는 정보를 보관하는 장치야. 전원이 유지되어야 내용을 유지하는 성질을 **휘발성**, 전원을 꺼도 정보를 유지할 수 있는 성질을 **비휘발성**이라고 해.

실제 비휘발성 장치도 보존 기간과 사용 조건의 한계는 있어.

일할 때 지금 쓰는 메모는 손 가까이에, 오늘 참고할 자료는 책상에, 오래 보관할 문서는 보관함에 둬. 모두 손안에 들고 있으면 빠르게 꺼낼 수 있겠지만 공간이 부족해.

반대로 매번 보관함까지 가면 일이 느려져.

컴퓨터도 하나의 기억 방식만으로 모든 요구를 만족시키기 어려워. SRAM, DRAM, NAND는 모두 정보를 보관하지만 구조와 적합한 역할이 달라.

## 2. 같은 0과 1을 서로 다르게 저장해

Module 1의 6T SRAM을 먼저 떠올려봐. 서로 연결한 인버터가 값을 유지했지? DRAM과 NAND는 그 자리에 다른 저장 방식을 사용하는 거야.

**셀**은 정보를 보관하는 기본 단위 회로 또는 구조야. Module 1의 대표적인 6T SRAM 셀은 여섯 트랜지스터를 사용해. 서로 상태를 지지하는 회로에 값을 저장하므로 전원이 공급되면 DRAM처럼 주기적으로 내용을 되살리는 동작이 필요하지 않아.

대표적인 DRAM 셀은 접근을 제어하는 트랜지스터와 전하를 보관하는 커패시터를 사용해. 커패시터는 두 도체 사이의 절연 구조에 전하를 저장하는 소자야.

저장한 전하가 시간이 지나며 줄어들기 때문에 주기적으로 확인하고 회복하는 **리프레시**가 필요해.

NAND 플래시는 절연된 저장 영역의 전하 상태를 이용해 트랜지스터가 켜지는 조건의 차이로 정보를 구별해. 전원이 꺼져도 전하가 비교적 오래 남게 설계돼.

읽기, 쓰기, 지우기의 방식과 시간이 서로 같지 않고, 쓰기·지우기 반복에도 수명 한계가 있어.

| 기억 방식 | 대표 저장 원리 | 전원 차단 시 | 대표 활용 |
|---|---|---|---|
| SRAM | 회로가 서로 상태를 유지 | 정보 소실 | 코어 가까운 캐시 |
| DRAM | 커패시터의 전하 | 정보 소실 | 주기억장치 |
| NAND | 절연된 영역의 전하 상태 | 정보 유지 가능 | 저장장치 |

## 3. 앞에서 배운 것과 연결해보자

소자를 어떻게 묶느냐가 저장 방식에 영향을 줘. 셀을 많이 배열하고, 원하는 위치를 고르고, 작은 전기적 차이를 읽는 주변 회로를 더하면 메모리 블록이나 메모리 칩이 돼.

셀 그림 하나가 메모리 제품 전체는 아니야.

## 4. 실제로는 어디에 쓰일까?

**캐시**는 자주 쓰거나 곧 쓸 가능성이 있는 데이터를 가까이 두어 느린 접근을 줄이는 역할이야. SRAM은 구현 기술이고 캐시는 역할이므로 같은 단어가 아니야. DRAM은 실행 중 데이터를 놓는 주기억장치에 널리 쓰이며, NAND는 SSD 같은 저장장치에서 사용돼. SSD는 Solid State Drive로, 반도체 메모리를 이용해 파일 등을 저장하는 장치야. SSD에는 NAND 외에 요청을 관리하는 컨트롤러도 필요해.

## 5. 잠깐, 네 말로 설명해볼까?

“컴퓨터 전원을 껐는데 문서 파일은 남고, 저장하지 않은 작업은 사라졌다”를 설명해 봐.

같이 확인해보자. 저장된 파일은 비휘발성 저장장치에 기록되어 남을 수 있어.

작업 중 일부 상태는 휘발성 메모리에만 있어서 전원 차단 시 사라질 수 있어. 실제 앱의 자동 저장 여부는 별도 조건이야.

손안·책상·보관함의 비유는 접근성과 보관 목적을 보여 주며 실제 구조나 정확한 속도 비율을 뜻하지 않아.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| SRAM | 대표적으로 트랜지스터 회로 상태로 정보를 유지하는 휘발성 메모리 |
| DRAM | 대표적으로 커패시터 전하를 이용하고 리프레시가 필요한 메모리 |
| NAND 플래시 | 전하 저장 상태를 이용하는 비휘발성 메모리 |
| 리프레시 | DRAM의 저장 정보를 주기적으로 회복하는 동작 |

## 오늘 반드시 기억할 3줄

**① SRAM·DRAM·NAND는 구조와 적합한 역할이 달라.**

**② SRAM도 휘발성이며 DRAM과 달리 주기적 리프레시가 필요하지 않아.**

**③ 캐시는 역할이고 SRAM은 구현 방식이야.**

## 오늘의 Quiz

**Q1. SRAM은 리프레시가 없으므로 전원을 꺼도 정보가 남을까?**

**Q2. DRAM에서 리프레시를 하는 이유는?**

**Q3. NAND 셀만 있으면 SSD 제품 전체가 완성될까?**

## 정답과 해설

**Q1**

아니야. 일반적인 SRAM은 전원이 필요하므로 휘발성이야.

**Q2**

셀의 저장 전하가 시간이 지나며 줄어들기 때문에 정보를 회복해야 해.

**Q3**

아니야. 데이터 요청, 오류와 저장 위치 등을 관리하는 컨트롤러와 연결 구조 등이 필요해.
