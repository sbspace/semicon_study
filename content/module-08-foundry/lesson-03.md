# Module 8 / Lesson 3
## 설계가 실제 칩이 되기까지 — Tape-out

공정 규칙에 맞춰 회로를 설계했어. 뉴스에는 이제 “Tape-out 완료”라고 나오네.

> “그럼 칩이 다 만들어진 거야?”

아직이야. 설계 데이터를 제조 쪽에 넘기는 이정표와, 실제 칩을 받아 쓰는 시점은 달라. 그 사이를 함께 따라가보자.

## 오늘 목표는 딱 하나야

> **Tape-out은 제조용 설계 데이터를 내보내는 단계이고, 뒤에 제조·조립·제품 검증이 남아 있어.**

## 1. 인쇄소에 원고를 넘겼다고 책이 나온 건 아니지?

**Tape-out**은 제조를 위한 최종 설계 데이터를 내보내는 이정표를 뜻해. 옛 저장 방식에서 온 이름이지만, 지금은 실제 테이프를 사용한다는 뜻으로 이해할 필요는 없어.

책을 만들 때 최종 원고를 인쇄소에 넘겼다고 독자가 책을 받은 것은 아니야. 인쇄 준비, 인쇄, 제본과 검수가 남아.

칩에서도 Tape-out 이후 마스크 준비, 웨이퍼 가공, 검사와 패키지 조립, 제품 검증이 이어져.

Module 8 Lesson 2에서는 공정 규칙에 맞게 설계하는 도구와 자료를 배웠지. 이번에는 그 설계가 물리 제품으로 넘어가는 지점을 봐.

## 2. 설계 데이터가 손에 잡히는 칩이 되기까지

Module 2의 배치·배선에서 Module 3의 가공, Module 6의 조립으로 넘어가는 길이야. 배운 내용을 시간 순서로 놓아보자.

**RTL**은 Register Transfer Level로, 디지털 회로의 데이터 이동과 동작을 기술하는 설계 표현이야. **물리 설계**는 실제 셀의 배치와 배선을 정하는 과정이야.

지금은 “무엇을 할지 표현한 설계”와 “어디에 놓고 어떻게 연결할지 정한 설계”를 구분하면 돼.

| 큰 단계 | 확인할 것 |
|---|---|
| 제품 요구·회로 설계 | 어떤 기능과 성능이 필요할까? |
| 구현·검증 | 실제 배치·배선과 동작 조건이 맞을까? |
| Tape-out·마스크 준비 | 제조할 데이터와 패턴이 준비되었는가? |
| 웨이퍼 가공·검사 | 소자와 연결이 설계대로 만들어졌는가? |
| 조립·최종 검증 | 완성된 제품이 실제 조건에서 동작할까? |

이 표는 큰 흐름이야. 모든 검증을 한 번씩 순서대로만 하는 것은 아니야.

설계 중에도 반복해서 검증하고, 실제 칩의 결과가 다음 설계 수정으로 돌아갈 수 있어.

<interactive type="design-to-silicon" />

설계 검증에서 놓친 기능 문제가 실제 칩에서 발견될 수도 있어. 반대로 설계는 맞아도 제조 변동이나 접합 문제가 생길 수 있어.

그래서 “제조 가능”, “논리 기능 정상”, “목표 성능 달성”, “장기간 안정적 동작”을 각각 확인해.

## 3. 작은 수량으로 먼저 만드는 이유

**MPW**는 Multi-Project Wafer로, 여러 프로젝트가 웨이퍼 제조 자원을 함께 활용하는 방식이야. 적은 수량의 시제품을 만들어 공정·설계를 검증할 때 비용 부담을 나누는 데 도움이 될 수 있어.

실제 제공 공정과 일정, 마스크 구성은 서비스마다 달라.

MPW가 설계 검증을 대신해주거나 양산과 완전히 같은 공급 조건을 보장하는 것은 아니야. 소량 시제품이 동작한 뒤에도 큰 수량에서의 수율·검사·신뢰성을 준비해야 해.

## 4. 앞에서 배운 것과 연결해보자

Tape-out 전의 물리 설계에는 Module 2의 Floorplan·Metal·Via가 들어가. Tape-out 뒤에는 Module 3의 Photo·Etch·Deposition 등이 반복돼. Module 6의 검사와 조립을 지나야 보드에서 사용할 제품이 돼.

## 5. 실제로는 어디에 쓰일까?

제조 이후의 문제를 설계 수정으로 해결하면 새 마스크와 재제조가 필요할 수 있어. 모든 수정의 범위가 같지는 않지만 일정과 비용에 영향을 주므로, 설계 검증과 제조 가능성 검토를 앞에서 충분히 하는 가치가 커.

공개 소식의 “Tape-out 완료”는 중요한 진전이지만 그 자체가 대량 출하 실적은 아니야. 다음 Module에서 기술 뉴스를 읽을 때 이 단계 차이를 다시 사용해.

## 6. 잠깐, 네 말로 설명해볼까?

가상의 뉴스에 “신형 칩 Tape-out 완료, 시제품 검증 예정”이라고 쓰여 있어. 이미 확인한 사실과 아직 남은 일을 나누어 말해봐.

같이 확인해보자. 제조에 보낼 설계 데이터가 준비된 이정표야.

실제 제조·조립과 시제품 동작 확인, 수율 확보와 대량 생산은 별도 단계야. 기사에 없는 출하 수량을 추정해 넣지 않아.
