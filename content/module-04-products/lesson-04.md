# Module 4 / Lesson 4
## SoC는 여러 역할을 어떻게 한데 묶을까?

CPU, GPU, NPU를 하나씩 봤지. 그런데 스마트폰 설명에는 또 SoC라는 말이 나와.

> “SoC도 CPU처럼 계산하는 부품 하나야?”

여기서는 보는 기준이 달라져. 오늘은 여러 역할을 한 칩 안에 모아놓는다는 뜻을 잡아보자.

## 오늘 목표는 딱 하나야

> **SoC는 여러 시스템 기능을 통합한 칩이고, 그 안에 CPU·GPU·NPU가 함께 들어갈 수 있어.**

## 1. 여러 부서가 있는 도시를 떠올려봐

**SoC**는 System on Chip의 약자로, 시스템을 구성하는 여러 핵심 기능을 칩에 통합한 것이야. 시스템은 한 가지 목적을 위해 함께 작동하는 구성 요소의 모음이야.

도시 안에 행정, 생산, 물류 시설이 함께 있는 모습을 생각하면 쉬워.

CPU는 실행 흐름을 관리하고 여러 일반 작업을 해. GPU는 많은 데이터를 병렬로 처리하고, NPU는 지원하는 신경망 계산을 맡을 수 있어. SoC는 이 역할들과 기억장치 연결, 외부 입출력 등의 기능을 함께 묶어. SoC를 CPU와 경쟁하는 또 다른 종류의 연산기 하나로 생각하면 헷갈려.

도시를 하나로 묶어도 전기, 물, 다른 도시와의 연결이 필요해. 마찬가지로 SoC에도 외부 메모리, 전원 공급 회로, 센서 등이 필요할 수 있어.

“시스템의 핵심을 통합했다”가 “완제품에 필요한 모든 것이 한 다이에 있다”는 뜻은 아니야.

## 2. 사진 한 장이 SoC 안을 지나간다면?

도시에 부서를 모아놨다고 협업이 저절로 되는 건 아니겠지? 칩 안에서도 블록 사이에 요청과 데이터를 전달하는 길이 필요해.

**인터커넥트**는 블록 사이에서 데이터를 전달하는 연결 구조야. **메모리 컨트롤러**는 메모리와 데이터를 주고받는 요청과 순서를 관리하는 회로야.

**I/O**는 입력과 출력, 즉 외부와 신호를 주고받는 기능이야.

| SoC의 구성 예 | 역할 |
|---|---|
| CPU 블록 | 프로그램 실행과 작업 제어 |
| GPU·NPU 블록 | 해당 구조에 잘 맞는 계산 수행 |
| 내부 연결망 | 블록 간 요청과 데이터 전달 |
| 메모리 컨트롤러 | 외부 메모리 접근 관리 |
| I/O 블록 | 센서·주변 장치 등과 연결 |

사진 처리의 단순한 흐름을 따라가 보자. 센서에서 데이터가 들어오고, 필요한 기억 공간에 놓이고, CPU가 작업을 준비하고, 지원되는 계산을 NPU가 처리하고, 결과가 화면 쪽으로 전달돼.

실제 사진 처리에는 별도 영상 처리 회로 등이 참여할 수 있으며, 이 예는 역할 분담을 위한 단순화야.

이 과정에서 각 블록이 빠르더라도 내부 연결망이나 외부 메모리 접근이 막히면 기다림이 생겨. 통합은 배치뿐 아니라 데이터 교통을 함께 설계하는 일이야.

## 3. 앞에서 배운 것과 연결해보자

Module 2에서 다이의 배치를 봤다면 이제 그 공간에 놓인 블록의 제품 역할을 읽을 수 있어. 다이는 물리적인 반도체 조각, 패키지는 다이를 보호하고 연결하는 구조야. SoC는 시스템 기능을 통합했다는 관점이야.

전통적으로 SoC는 한 칩 통합을 뜻하지만, 실제 제품의 명명에서는 여러 다이를 이용한 통합 시스템에도 관련 표현이 쓰일 수 있어. 그래서 제품 이름만으로 다이 개수를 단정하지 말고 구조 설명을 확인해.

## 4. 실제로는 어디에 쓰일까?

스마트폰의 주요 처리 칩은 SoC의 익숙한 예야. CPU와 GPU가 둘 다 있다고 해서 각각 별도 패키지여야 하는 것은 아니야. 반대로 별도 메모리 패키지가 옆에 있다고 해서 SoC가 아닌 것도 아니야.

## 5. 잠깐, 네 말로 설명해볼까?

“GPU가 들어 있는 SoC 다이 하나가 패키지 안에 있다”는 문장에서 GPU, SoC, 다이, 패키지를 각각 분류해 봐.

같이 확인해보자. GPU는 처리 기능, SoC는 여러 시스템 기능을 통합한 설계, 다이는 물리 조각, 패키지는 그것을 연결하고 보호하는 구조야. 같은 대상을 서로 다른 높이에서 설명하므로 네 단어가 함께 쓰일 수 있어.

## 오늘 핵심 용어

| 용어 | 이 수업에서의 뜻 |
|---|---|
| SoC | 여러 시스템 핵심 기능을 칩에 통합한 것 |
| 인터커넥트 | 기능 블록 사이의 데이터 연결 구조 |
| 메모리 컨트롤러 | 메모리 접근 요청과 동작을 관리하는 회로 |
| I/O | 외부와 입력·출력 신호를 주고받는 기능 |

## 오늘 반드시 기억할 3줄

**① SoC 안에 CPU·GPU·NPU 등 여러 기능이 들어갈 수 있어.**

**② SoC라는 명칭과 물리적 다이·패키지 수는 구분해서 읽어.**

**③ 통합 시스템의 성능은 블록 사이 데이터 전달에도 달려 있어.**

## 오늘의 Quiz

**Q1. CPU와 SoC는 서로 배타적인 제품 분류일까?**

**Q2. SoC면 외부 메모리가 절대로 필요 없을까?**

**Q3. 모든 연산 블록이 빨라져도 연결망이 혼잡하면 어떤 일이 생기는가?**

## 정답과 해설

**Q1**

아니야. SoC 안에 CPU 기능 블록이 들어갈 수 있어.

**Q2**

아니야. 어떤 기능을 통합했는지에 따라 외부 메모리나 다른 부품이 필요해.

**Q3**

블록이 데이터를 기다리므로 전체 처리 속도 개선이 제한될 수 있어.
