# Module 9 Review — 최신 트렌드

새로운 기술 이름을 전부 외울 필요는 없어. 기사를 읽으면서 “무엇을 바꿨지? 어떤 문제를 줄였지? 어디까지 실제로 확인됐지?”를 물을 수 있으면 돼. 마지막으로 그 관점을 연결해보자.

정답은 아래에 바로 있어. 먼저 떠올려보고 확인해봐.

## 1. 먼저 큰 그림부터 다시 보자

2026년 자료를 읽을 때는 기술이 해결하는 문제, 실제로 바뀐 구조, 증명된 단계, 비교 조건을 찾아. GAA는 채널 제어, 후면 전력은 전력 경로, High-NA는 패턴 형성, HBM은 데이터 공급, 칩렛 연결 표준은 다이 간 통신과 협업의 문제에 연결돼. 이 개선들은 제품 안에서 함께 작동하지만 서로를 자동으로 보장하지 않아.

## 2. 이 말들은 꼭 구분하자

| 비교 | 구분 기준 |
|---|---|
| 기술 발표 / 실증 / 양산 / 출하 | 자료가 실제로 입증하는 단계까지만 말해. |
| 사건 날짜 / 발표 날짜 / 확인 날짜 | 일이 일어난 때와 알려진 때, 교재에서 확인한 때를 구분해. |
| 규격 최고값 / 제품 사양 / 실제 성능 | 표준 지원 범위와 구현된 기능, 실제 작업 결과는 다른 정보야. |
| 적층 수 / 용량 / 대역폭 | 층 수는 구조, GB는 저장량, GB/s·TB/s는 이동량이야. |
| 개별 개선 / 전체 개선 | 바꾸지 않은 구간의 시간과 제한이 남아. |

## 3. 지금까지 배운 것과 이어보자

전체 교재의 연결은 “전기적 성질을 이용해 소자를 만들고, 소자를 회로로 연결하고, 회로를 칩 안에 배치하고, 공정으로 제조하고, 패키지로 연결해 제품을 만든다”야. 산업은 이 작업을 나누어 해. 최신 기술은 그 연결 중 특정 문제를 해결하려는 변화로 읽으면 돼.

## 4. 네 말로 한 번 묶어볼까?

새 기술 기사 한 편을 골라 ① 해결 문제 ② 구조 위치 ③ 확인된 단계 ④ 출처·날짜 ⑤ 추가 확인할 내용을 다섯 문장으로 적어봐. 이어 Module 0~8 중 관련 Lesson 두 개를 연결해. 최신 숫자를 외우는 대신, 근거가 바뀌어도 설명을 갱신할 수 있는 틀을 만드는 연습이야.

## 누적 Quiz — 같이 확인해보자

**Q1. GAA와 후면 전력 공급은 같은 구조일까?**

**Q2. High-NA의 NA를 높였다는 말은 EUV 파장을 그만큼 줄였다는 뜻일까?**

**Q3. 인용된 Micron 3월 발표에서 12H와 16H 상태를 어떻게 구분했는가?**

**Q4. UCIe 표준이 있으면 실제 조합 검증이 없어도 될까?**

**Q5. 이동 6초와 계산 4초 중 계산만 두 배 빨라지면 전체는?**

**Q6. 예정된 양산 날짜가 지났을 때 교재를 어떻게 수정해야 할까?**

**Q7. 새 반도체 기사를 처음 읽을 때 사용할 질문 네 가지는?**

## 정답과 해설

**Q1**

아니야. 앞의 것은 채널 제어, 뒤의 것은 전력 경로의 변화야.

**Q2**

아니야. 광학계의 개구수를 높인 것이야.

**Q3**

36GB 12H는 대량 출하, 48GB 16H는 샘플 제공으로 구분했어. 이 발표 이후 상태는 새 자료로 확인해.

**Q4**

아니야. 지원 조건과 기능·물리 통합·검증을 확인해.

**Q5**

순차 가정에서 8초야. 남은 이동 시간은 그대로야.

**Q6**

완료 여부를 공식 후속 자료로 확인한 뒤 현재 상태를 갱신해. 과거 계획을 자동으로 실적 처리하지 않아.

**Q7**

무슨 문제를 해결하는가, 어느 구조가 바뀌는가, 어떤 단계까지 확인되었는가, 비교 조건과 출처 날짜는 무엇인가야.
